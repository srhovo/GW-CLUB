# 养成系club · 请宝宝挑选心仪陪玩
一个面向「老板/宝宝」的陪玩选人与服务展示页面。移动端优先，含：
- **挑选陪玩**：按价位 + 分路双维度筛选（价位/分路旁显示对应人数），双列卡片墙展示自介卡，点击卡片自动播放音介视频；标题图撑满屏幕直贴顶部，右侧配一个可爱气泡按钮打开「注意事项」
- **服务清单**：价格表 / 预存表 / 结算规则 / 礼物单 / 活动图，每栏都支持**多张图片**，每张图有自己的自定义标题，点缩略图看大图（不裁切）
- **选图**：板卡 / 冠卡 / 礼物单 / 开黑卡 / 成长录 / 守护星 / 领养卡 / 生日卡 / VIP卡 / 结单小票，用法与服务清单一致，另外每张图可以配一句「获取条件」，点开大图后显示在下方
- **管理层信息**：团长 / 副团 / 管理微信号卡片，支持自定义头像，点击即可复制微信号
- **搜索**：支持名字、分路、价位、服务清单/选图图片名等关键字，以及拼音首字母组合（如 `dy`=打野、`zl`=中路、`yuji`=雨季）；「热门」气泡按本机搜索历史动态排序（前 5 高频 + 后 4 最近）
- 底部 Tab 切换五个页面，纯静态、无后端，可直接部署到 GitHub Pages
## 目录结构
```
dudu/
├── index.html        # 应用主体（界面 + 逻辑，一般不需要改）
├── data.js           # ★ 内容数据（陪玩 / 价格 / 预存 / 活动 / 礼物 / 结算规则 / 管理层 / 注意事项，日常更新改这里）
├── assets/
│   ├── cards/        # 自介卡图片（放这里）
│   ├── voices/       # 音介视频（放这里，务必用 .mp4）
│   ├── management/   # 管理层头像（按职位命名，见下）
│   ├── services/     # 服务清单图片（价格表/预存表/结算规则/礼物单/活动图，每栏可放多张）
│   └── gallery/      # 选图图片（板卡/冠卡/礼物单/开黑卡/成长录/守护星/领养卡/生日卡/VIP卡/结单小票，每栏可放多张）
└── README.md         # 本文档
```
## 素材规范（重点）
| 素材 | 推荐比例 | 建议格式 | 存放位置 / 命名 |
|---|---|---|---|
| 自介卡图片 | **2096:1279（约 5:3）** | png / jpg / webp | `assets/cards/`（建议 `名字.jpeg`） |
| 音介视频 | **2096:1279（约 5:3）** | **mp4**（手机/电脑都能播） | `assets/voices/`（建议 `名字.mp4`） |
| club 标题图 | 横幅（会撑满屏幕宽度，高度自动等比） | png / jpg / webp | `assets/club-logo.png`（见下） |
| 管理层头像 | 建议 1:1（圆形裁切） | png / jpg / webp | `assets/management/`（按职位命名，见下） |
| 价格表 / 预存表 / 结算规则 / 礼物单 / 活动图 | 不限，长图也没问题（查看大图时完整显示不裁切） | png / jpg / webp | `assets/services/`（每栏可放多张，见下） |
| 板卡 / 冠卡 / 礼物单 / 开黑卡 / 成长录 / 守护星 / 领养卡 / 生日卡 / VIP卡 / 结单小票（选图） | 不限 | png / jpg / webp | `assets/gallery/`（每栏可放多张，见下） |

> ⚠️ **视频一定要用 .mp4**：`.mov` 在安卓/微信/部分 Chrome 上无法播放。若手头只有 `.mov`，可用任意视频转换工具或 ffmpeg 转成 mp4 再上传。

### club 标题图 / 管理层头像「自动生效」
图片**按约定命名上传后无需改代码**，页面会自动识别（支持 .png/.jpg/.jpeg/.webp）：
- club 标题图：`assets/club-logo.png`（或 `club-title.png` / `club.png`）；未上传时以「养成系club」文字兜底
- 管理层头像：按职位命名，如 `assets/management/团长.png`、`副团.png`、`管理.png`；未上传时用昵称首字圆形占位
- 也可以直接改 `data.js` 里 `club.logo` 与各 management 条目的 `avatar` 手动指定路径（若两者都有，自动识别到的文件优先）

### 服务清单图片：多图 + 自定义名字
价格表/预存表/结算规则/礼物单/活动图这五栏，**每栏可以放任意数量的图片**，每张图都有自己的标题（显示在缩略图上方，也能被搜索到）。因为是纯静态站点，没法自动扫描文件夹里有哪些文件，所以每张图都要在 `data.js` 里写一行——但只是复制粘贴一行的工作量：
```js
price: {
  images: [
    { name: '常驻价格表', image: 'assets/services/price.jpg' },
    { name: '周年庆特惠价格表', image: 'assets/services/price-2.jpg' }   // 新增一张就加一行
  ],
  items: [ /* 文字版数据，用于搜索，见下方说明 */ ]
}
```
- `name`：自定义标题，随便取，会显示在缩略图上方，也可以被搜索到
- `image`：图片路径（`assets/services/xxx.jpg`）或外链
- 想删除某张图，直接删掉对应那一行即可；顺序就是数组里的顺序
- 结算规则是新加的一栏，默认 `images: []`（空），上传第一张图后按上面格式加一行就行
- 页面上点击任意一张缩略图，会弹出该图的完整大图（不裁切、不受固定比例限制）

### 选图图片：多图 + 自定义名字 + 获取条件
用法跟服务清单完全一样，多一个可选字段 `condition`（获取方式），会显示在点开大图后的下方：
```js
board: {
  images: [
    { name: '青铜板卡', image: 'assets/gallery/board-1.jpg', condition: '首次下单即可获得' },
    { name: '钻石板卡', image: 'assets/gallery/board-2.jpg', condition: '累计消费满 500r 解锁' }
  ]
}
```
- `condition` 留空就不显示这一行，所有分类（板卡/冠卡/礼物单/开黑卡/成长录/守护星/领养卡/生日卡/VIP卡/结单小票）用法完全一致
- 这里的「礼物单」和服务清单里的「礼物单」是两个独立的分类，互不影响，可以放不同内容

## 性能优化说明
这版做了几处优化，加载会明显变快：
- 首图/服务图/头像等素材做了压缩重编码（原图几千像素、几百 KB～1MB+ → 统一压缩到合理尺寸后普遍降到几十～几百 KB），肉眼画质基本无损
- 音介视频重新编码（H.264 + faststart），同画质下体积大幅缩小，且支持边下边播
- 素材自动探测（club 标题图 / 管理层头像）改成并发探测，不再排队等待，首屏出图更快
- 首图（club 标题图）标记了高优先级加载

**以后新增图片/视频，建议按这个标准处理再上传**（不然体积可能又变大）：
| 素材类型 | 建议长边像素 | 说明 |
|---|---|---|
| 自介卡 / 选图卡片类图片 | 1000～1200px | 手机屏幕够用，无需上传原图 |
| 价格表等长图/文字类图片 | 900～1000px 宽 | 保证文字清晰即可，不用原始分辨率 |
| club 标题横幅 | 1600px 宽左右 | 撑满屏幕也够清晰 |
| 视频 | 720p～960p 足够，控制在 15～30 秒 | 用 ffmpeg 转码可参考：`ffmpeg -i in.mp4 -vf "scale=960:-2" -c:v libx264 -preset slower -crf 27 -movflags +faststart -c:a aac -b:a 96k -ac 1 out.mp4` |

> 如果压缩之后加载还是感觉慢，很可能不是素材大小的问题，而是**访问线路**的问题：GitHub Pages 在国内的访问速度/稳定性一直不太理想。如果客人主要在国内访问，可以考虑把这个仓库也接入 Cloudflare Pages（跟你另一个项目「码单器」用的是同一套免费方案，直接在 Cloudflare 后台关联这个 GitHub 仓库即可，几分钟搞定，仓库内容完全不用改），实际体验提升可能比单纯压缩图片更明显。
## 部署到 GitHub Pages（一次性）
1. 在 GitHub 上新建仓库，如 `dudu`，不要勾选「Add a README」（空仓库即可）。
2. 本地把项目推进仓库：
```bash
cd dudu
git init
git add .
git commit -m "init: 养成系club"
git branch -M main
git remote add origin https://github.com/<你的用户名>/dudu.git
git push -u origin main
```
3. 打开仓库 → **Settings → Pages** → Source 选择 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save。
4. 等 1～2 分钟访问：
```
https://<你的用户名>.github.io/dudu/
```
以后每次 `git push` 页面自动更新，无需重新配置。
## 日常更新内容
### 新增 / 修改一位陪玩
1. 自介卡图片放 `assets/cards/`，音介视频放 `assets/voices/`（**转成 mp4**）。
2. 打开 `data.js`，在 `companions` 里加一条（或改对应条目）：
```js
{ id: 'yuji', name: '雨季', lanes: ['打野','中路'], price: 30,
  tags: ['顶技','镜'], intro: '无忧无虑 · 主玩英雄：镜',
  image: 'assets/cards/雨季.jpeg',
  video: 'assets/voices/雨季.mp4' }
```
字段说明：
| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，英文/数字，不能重复（也可用于拼音搜索） |
| `name` | 是 | 展示名 |
| `lane` / `lanes` | 是 | 单分路写 `lane`；多分路写数组 `lanes`，如 `['打野','中路']` |
| `price` | 是 | 价位数字（单位 r），需在 `prices` 列表内 |
| `tags` | 否 | 标签数组，用于搜索 |
| `intro` | 否 | 一句话自介，用于搜索 |
| `image` | 否 | 自介卡路径；留空显示占位 |
| `video` | 否 | 音介视频路径（mp4）；留空则点击卡片显示自介卡并提示待上传 |
> 图片/视频既可用相对路径（`assets/cards/xx.png`），也可用外链（`https://...`）。
3. 提交推送：
```bash
git add .
git commit -m "新增陪玩：雨季"
git push
```
### 新增 / 修改一张服务清单图片（价格表 / 预存表 / 结算规则 / 礼物单 / 活动图）
1. 图片放进 `assets/services/`。
2. 打开 `data.js`，在对应分类的 `images` 数组里加一行 `{ name:'自定义标题', image:'assets/services/文件名.jpg' }`（具体写法见上方「服务清单图片」一节）。
3. 文字版数据（仅价格表/预存表/礼物单有，用于搜索，不在页面直接展示）在同一节点的 `items` 里改。
4. 改完把 `updateDate` 更新为当天日期，页面会展示「更新于 日期」。
### 新增 / 修改一张选图图片（板卡 / 冠卡 / 礼物单 / 开黑卡 / 成长录 / 守护星 / 领养卡 / 生日卡 / VIP卡 / 结单小票）
1. 图片放进 `assets/gallery/`。
2. 打开 `data.js`，在 `gallery` 对应分类的 `images` 数组里加一行 `{ name:'自定义标题', image:'assets/gallery/文件名.jpg', condition:'获取方式（可选）' }`（见上方「选图图片」一节）。
### 修改管理层 / 注意事项
在 `data.js` 的 `management`（团长/副团/管理微信号，及可选的 `avatar` 头像路径）与 `notes`（注意事项标题与条目）里改即可；头像也可以直接把文件按职位命名放进 `assets/management/` 自动生效，见上方说明。
### 关于「热门」搜索气泡
热门气泡是**按访客自己这台设备/浏览器**的搜索记录动态生成的（存在浏览器 localStorage 里），不是全体客人共享的排行榜——纯静态站点没有后端，做不到跨设备统计。数据不需要手动维护，用户点得越多、越新，气泡顺序自动更新；换设备或清浏览器缓存会重新开始计数。
### 修改价位档位 / 分路分类
改 `data.js` 顶部的 `prices`、`lanes` 数组，页面的筛选按钮与数量会自动重算。
## 本地预览
直接双击 `index.html` 用浏览器打开即可；也可以起本地服务：
```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
## 常见问题
- **点卡片没视频播放？** 检查 `video` 字段是否填了路径、视频是否已放进 `assets/voices/` 并推送；确认是 **mp4** 格式。
- **图片变形？** 自介卡请按 5:3 制作；非 5:3 的图会以居中裁剪方式展示，主体建议放在画面中上部。
- **服务清单的图片缩略图裁掉了内容？** 缩略图是裁剪预览，方便一眼看出是哪张图；点开看大图时是完整显示、不裁切，不用担心内容被裁掉。
- **管理层头像没生效？** 确认文件名和职位完全一致（如 `团长.jpg`，职位名要跟 `data.js` 里 `role` 字段一致），且已经推送到 `assets/management/` 目录。
- **搜索新名字搜不到拼音？** 中文关键字搜索始终可用；拼音首字母依赖 `index.html` 里的拼音字典，新字未收录时可在字典补一条（`'字':'首字母'`），或直接搜中文。
- **"注意事项"入口在哪？** 现在是"挑选"页标题右边的粉色气泡按钮，不再是左上角固定按钮；因为按钮跟着标题走，目前只在"挑选"这一页能看到。如果想让其他页面也能打开，告诉我加一个入口。
